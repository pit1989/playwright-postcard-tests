# Postcard QA Automation Project

Проект с UI автотестами для сайта:
https://postcard.qa.studio/

## Что использовалось
- Python
- Playwright
- Pytest
- Page Object Model (POM)

## Структура проекта

project/
│
├── pages/
│   └── postcard_page.py
│
├── tests/
│   ├── test_smoke.py
│   ├── test_validation.py
│   ├── test_image.py
│   ├── test_submission.py
│
├── conftest.py
└── README.md

## Что тестировалось
- Проверка отображения кнопки “Отправить”
- Проверка пустого email
- Проверка невалидного email
- Проверка пустой формы
- Загрузка изображения
- Переключение между изображениями
- Отправка формы
- Негативные сценарии
- Проверка ограничения символов в message field

## Найденные баги
- Ограничение в 200 символов не работает
- Форму можно отправить без email при выборе картинки
- После закрытия модального окна форма не обновляется
- Ошибки валидации остаются после успешной отправки формы

## Как запускать тесты

Запуск всех тестов:

pytest

Запуск с подробным выводом:

pytest -v

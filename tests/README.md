# Selenium + Pytest UI Autotests

Автоматизированные UI-тесты для сайта https://postcard.qa.studio/  
Стек: Python, Selenium WebDriver, Pytest.  
Результаты выполнения тестов можно просматривать в отчётах Allure.

## Обнаруженный дефект тестируемого сайта

**Описание:**  
При выборе изображения форма отправляется даже если обязательные поля (email, комментарий) не заполнены.

**Фактический результат:**  
Форма успешно отправляется и появляется сообщение "Открытка успешно отправлена!".

**Ожидаемый результат:**  
Форма не должна отправляться, пока обязательные поля не заполнены.

**Комментарий:**  
Без выбора изображения в форме отображаются ошибки обязательных полей, что указывает на неконсистентную логику валидации.
